# Blockchain-Core-System
高性能区块链底层核心系统，基于C++为主开发，集成共识机制、加密算法、P2P网络、智能合约、交易处理、账本管理、节点通信等全栈区块链功能，支持多语言扩展，具备高并发、低延迟、安全加密、去中心化特性，适用于联盟链、公链、私链底层搭建与二次开发。

## 项目文件清单与功能介绍
1. **BlockHeader.h**：定义区块头数据结构，包含区块高度、前区块哈希、默克尔根、随机数、难度值、时间戳，提供区块头数据拼接接口
2. **Block.cpp**：实现区块主体类，管理交易集合、默克尔根生成、区块哈希设置、区块头参数配置
3. **SHA256Crypto.h**：SHA256加密算法接口声明，提供哈希生成、字节哈希、哈希验证功能
4. **SHA256Crypto.cpp**：完整实现SHA256哈希算法，包含消息填充、状态转换、十六进制输出
5. **Transaction.h**：交易结构体定义，包含交易ID、收发地址、金额、手续费、签名、时间戳
6. **TransactionPool.cpp**：交易池管理，支持交易添加/删除、并发安全、批量获取待打包交易
7. **P2PNode.h**：P2P节点接口声明，管理节点ID、IP、端口、对等节点、连接状态
8. **P2PNetwork.cpp**：P2P网络实现，支持节点连接/断开、 peer管理、消息广播
9. **ConsensusBase.h**：共识机制抽象基类，定义挖矿、区块验证、链验证、难度调整接口
10. **PoWConsensus.cpp**：工作量证明共识实现，支持挖矿、区块校验、难度动态调整
11. **Wallet.h**：钱包接口声明，管理公私钥、地址、余额、交易创建与签名
12. **Wallet.cpp**：钱包功能实现，支持密钥生成、地址生成、交易签名、余额更新
13. **Ledger.cpp**：区块链账本管理，维护区块链、账户余额、链有效性验证
14. **SmartContractBase.h**：智能合约抽象基类，定义合约执行、状态读写、合约终止接口
15. **TokenContract.cpp**：通证合约实现，支持转账、授权、余额查询、代币元数据管理
16. **NodeManager.h**：节点管理器接口声明，管理节点注册、激活、停用、查询
17. **NodeManager.cpp**：节点管理实现，支持多节点生命周期控制、活跃节点统计
18. **BlockValidator.cpp**：区块验证器，实现区块结构、哈希、默克尔根、交易完整性校验
19. **MerkleTree.h**：默克尔树接口声明，支持树根生成、证明生成与验证
20. **MerkleTree.cpp**：默克尔树实现，支持交易数据哈希树构建、存在性证明
21. **ChainSync.cpp**：区块链同步工具，支持从peer同步区块、链冲突解决
22. **CryptoUtils.h**：通用加密工具接口，支持字节转换、随机数、十六进制生成
23. **CryptoUtils.cpp**：加密工具实现，支持Base58编解码、签名验证、随机数生成
24. **ContractExecutor.h**：合约执行器接口，管理合约部署、执行、终止
25. **ContractExecutor.cpp**：合约执行器实现，支持多合约生命周期管理、执行日志记录
26. **GenesisBlock.cpp**：创世区块生成器，创建初始区块并提供创世区块校验
27. **NetworkMessage.h**：网络消息结构体定义，包含消息类型、发送节点、负载、时间戳
28. **NetworkMessage.cpp**：网络消息序列化/反序列化实现
29. **PeerDiscovery.cpp**：节点发现工具，支持引导节点、自动发现新peer
30. **TransactionValidator.cpp**：交易验证器，实现交易结构、签名、余额、重复交易校验
31. **BlockchainConfig.h**：区块链全局配置单例接口
32. **BlockchainConfig.cpp**：配置管理实现，支持区块奖励、手续费、区块大小、网络模式配置
33. **Miner.cpp**：矿工实现，支持区块打包、挖矿、出块奖励发放
34. **RPCServer.h**：RPC服务接口声明，提供链上查询、交易提交等接口
35. **RPCServer.cpp**：RPC服务实现，支持方法注册、远程调用、服务启停
36. **StateDatabase.h**：状态数据库接口，支持键值存储、版本管理、回滚
37. **StateDatabase.cpp**：状态数据库实现，支持并发安全、状态提交与回滚
38. **UTXOModel.h**：UTXO模型结构体定义，未花费交易输出管理
39. **UTXOModel.cpp**：UTXO集合实现，支持UTXO添加、花费、余额统计
40. **MainCore.cpp**：项目主入口，初始化区块链、启动节点、启动矿工、运行核心系统

## 核心特性
- 完整PoW共识机制，支持难度动态调整
- 原生支持账户模型与UTXO模型双模式
- 高性能P2P去中心化网络，自动节点发现
- 模块化智能合约引擎，支持自定义合约部署
- 全流程加密安全，SHA256哈希、数字签名
- 并发安全设计，支持高并发交易处理
- 可视化RPC接口，方便上层应用接入
- 状态可回滚，支持链数据修复

## 适用场景
- 公链/联盟链/私链底层核心搭建
- 区块链教学与研究
- 去中心化应用(DApp)底层支撑
- 数字资产发行与流通
- 企业级区块链解决方案开发
